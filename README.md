# BookSmart
Full-Stack Book Management System
Technologies: C#, ASP.NET Core, React, Entity Framework Core, SQL Server, REST APIs, Swagger/OpenAPI

• Engineered a layered full-stack application with ASP.NET Core, React, Entity Framework Core, and SQL Server, separating presentation, API, business-logic, and persistence concerns.

• Designed Swagger-documented CRUD REST APIs, relational entity models, server-side validation, and responsive client workflows for reliable database-backed record management
